# Equivalent assertion fixtures

Each case uses the original recall matcher strings and desired findings. Configured assertionModules entries match the literal require/require_relative specifier and identify original synthetic providers; the Ruby adapter does not yet implement this assertion trust contract. Undeclared providers are intentionally identical sources. Provider spelling alone never grants trust. These groups must continue failing until provider semantics, mutation invalidation and assertion-aware similarity meet their oracles.

The group path is the shared equivalent-assertions root so each isolated run can resolve its provider sources. --definitions selects only the case handlers, and --config selects that case configuration. No Ruby application code is executed by the parity checker. Each mapping documents translated dimensions and narrow excluded syntax/API.

Namespace factory objects are original callable proxies that capture method(:expect) and delegate call to that explicitly exported Method. Their modifier and nested-builder members express the JavaScript callable-with-properties dimension through Ruby objects. The exported expect(actual) has no added overload. A configured file identity does not grant trust to arbitrary helper return values.
