# Code of conduct

CukeDedup contributors are expected to keep project spaces welcoming, professional, and focused on constructive technical collaboration.

Harassment, discrimination, threats, deliberate intimidation, publication of private information, and sustained disruptive behavior are not acceptable. Maintainers may edit or remove contributions and temporarily or permanently restrict participation when necessary to protect the community.

Do not publish sensitive personal information in a repository issue. Report harassment, threats, doxxing, or other violations of GitHub's policies through [GitHub's private Report Abuse form](https://support.github.com/contact/report-abuse). This file will name a direct project-maintainer contact when a dedicated private channel is available.
